## Build — Rust Binary (vodou-core)

Full rebuild cycle — kills running processes, compiles, copies to project root, restarts:

```bash
# 1. Stop running processes
pkill -f "vodou-core worker" 2>/dev/null
pkill -f "vodou-core daemon" 2>/dev/null
sleep 1

# 2. Build release binary
cargo build --release

# 3. Copy to project root (this is what ./oi and all scripts call)
cp target/release/vodou-core ./vodou-core

# 4. Restart services
./vodou-core daemon start &
./vodou-core worker start &
```

**Debug build** (faster compile, bigger binary, more checks):
```bash
pkill -f "vodou-core worker" 2>/dev/null
pkill -f "vodou-core daemon" 2>/dev/null
sleep 1
cargo build
cp target/debug/vodou-core ./vodou-core
./vodou-core daemon start &
./vodou-core worker start &
```

**Quick restart only** (no rebuild):
```bash
pkill -f "vodou-core worker" 2>/dev/null
pkill -f "vodou-core daemon" 2>/dev/null
sleep 1
./vodou-core daemon start &
./vodou-core worker start &
```

## Build — Gateway (Vodou-Console)

```bash
cd MCP-servers/Vodou-Console && npm run build && cd ../..
```

Gateway runs as part of `./start-vodou-services.sh` or standalone:
```bash
node MCP-servers/Vodou-Console/dist/index.js
```

## Build — Full Services Restart

```bash
./start-vodou-services.sh              # Normal startup (all services)
DEBUG=1 ./start-vodou-services.sh      # Verbose debug mode with timeouts
```
