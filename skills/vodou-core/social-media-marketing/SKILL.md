# Vodou Social Media Marketing - Post Creation & Selection Workflow

## Overview

This skill guides you through a comprehensive 3-step workflow for creating effective social media marketing posts for insurance companies like AAA Insurance. The workflow ensures quality through creation, critical analysis, and strategic selection.

**The Workflow:**
1. **Step 1**: Create multiple post variations
2. **Step 2**: Critical analysis and deep evaluation
3. **Step 3**: Select the best post for use

## Prerequisites

- Company information (name, industry, target audience)
- Marketing goals and objectives
- Brand voice and tone guidelines
- Target platform (Facebook, Twitter/X, LinkedIn, Instagram, etc.)

## Core Workflow

### Step 1: Create Multiple Post Variations

**⏸️ STOPPING POINT 1**: Gather company and campaign information.

Before creating posts, I need to understand:

1. **Company Details:**
   - Company name (e.g., AAA Insurance)
   - Industry/sector
   - Target audience demographics
   - Brand voice (professional, friendly, authoritative, etc.)

2. **Campaign Goals:**
   - What is the primary objective? (awareness, engagement, conversions, education)
   - Key message or value proposition
   - Call-to-action (CTA) requirements

3. **Platform & Format:**
   - Which social media platform(s)?
   - Post format (text, image, video, carousel)
   - Character limits and constraints

4. **Timing & Context:**
   - Is this for a specific campaign, event, or season?
   - Any current events or trends to consider?

**Please provide this information, or say "use AAA Insurance as example" to proceed with a sample workflow.**

---

**Once I have the information, I'll create 5-7 post variations:**

Each post will have:
- **Headline/Hook**: Attention-grabbing opening
- **Body Content**: Key message and value proposition
- **Call-to-Action**: Clear next step
- **Hashtags** (if applicable): Relevant tags for discovery
- **Tone**: Matching brand voice

**⏸️ STOPPING POINT 2**: Review the created posts.

After creating the posts, I'll present them for your review. You can:
- Request modifications to any post
- Ask for additional variations
- Proceed to critical analysis

**Say "proceed to step 2" or "analyze these posts" to continue.**

---

### Step 2: Critical Analysis & Deep Evaluation

**⏸️ STOPPING POINT 3**: Begin critical analysis.

I'll analyze each post against multiple criteria:

**Analysis Framework:**

1. **Engagement Potential:**
   - Is the hook compelling?
   - Does it stop the scroll?
   - Will it generate likes, comments, shares?

2. **Message Clarity:**
   - Is the core message clear and concise?
   - Does it communicate value effectively?
   - Is it easy to understand?

3. **Brand Alignment:**
   - Does it match brand voice and tone?
   - Is it appropriate for the industry?
   - Does it build trust and credibility?

4. **Call-to-Action Effectiveness:**
   - Is the CTA clear and compelling?
   - Does it drive the desired action?
   - Is it easy to follow?

5. **Platform Optimization:**
   - Is it optimized for the target platform?
   - Does it use platform-specific features?
   - Is the length appropriate?

6. **Target Audience Resonance:**
   - Will it resonate with the target audience?
   - Does it address their pain points?
   - Is it relevant and timely?

7. **Competitive Differentiation:**
   - Does it stand out from competitors?
   - Is it unique and memorable?
   - Does it highlight unique value?

**For each post, I'll provide:**
- Strengths and weaknesses
- Engagement score (1-10)
- Message clarity score (1-10)
- Brand alignment score (1-10)
- Overall recommendation

**⏸️ STOPPING POINT 4**: Review the analysis.

After the critical analysis, I'll present:
- Detailed evaluation of each post
- Comparative analysis
- Recommendations for improvement
- Top 2-3 contenders

**Say "proceed to step 3" or "select best post" to continue.**

---

### Step 3: Select the Best Post

**⏸️ STOPPING POINT 5**: Final selection.

Based on the analysis, I'll recommend the best post and explain why:

**Selection Criteria:**
1. **Highest Overall Score**: Best combination of all factors
2. **Campaign Goal Alignment**: Best match to primary objective
3. **Platform Optimization**: Best fit for target platform
4. **Audience Resonance**: Best connection with target audience
5. **Brand Voice**: Best representation of brand

**Final Recommendation Will Include:**
- The selected post (full text)
- Why it was selected (key strengths)
- How to optimize it further (optional improvements)
- Suggested posting schedule/timing
- A/B testing recommendations (if applicable)

**⏸️ STOPPING POINT 6**: Confirm selection or request changes.

You can:
- Accept the recommendation
- Request modifications
- Ask for a different selection
- Request additional variations

**Say "accept" or "use this post" to finalize, or request changes.**
