## Customization Guide

### For Simple Skills
- Remove "Advanced Usage" section
- Reduce to 3-5 steps
- Include 2-3 stopping points
- Keep examples simple

### For Complex Skills
- Add more workflow paths
- Include orchestration directives
- Add more stopping points
- Include multiple example scenarios
- Add "Best Practices" section

### For Orchestrated Skills
- Add orchestration metadata
- Include conditional workflows
- Add cross-server integration
- Include dynamic stopping points
