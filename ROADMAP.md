# Roadmap

A living view of where the open Vodou client is headed. Not promises — direction. Open an
issue or Discussion to weigh in. (For anything engine-internal, note the engine is
proprietary; the roadmap here covers the open surface.)

## Now
- **Open-core launch** — MIT client + proprietary engine, clean install on all platforms
- **Memory Follows You** hardening — better retrieval for how people actually phrase things
- **Leak policy** — user-controlled "never share this" rules for what travels to external AIs

## Next
- More **browser-capture adapters** (new AI surfaces) — a great first contribution
- **Skills** ecosystem — easier authoring + sharing
- Windows/Linux install polish and signing
- A measurable **inject-quality gate** users can run themselves

## Later / exploring
- Read-time query understanding for retrieval (opt-in)
- Team/enterprise governance (per-tenant sharing policy, audit)
- Pocket-access relay (use your memory from mobile / connectors)

## How to influence it
- 👍 react to issues you care about
- Propose additions via a **feature request** issue
- Pick up a **`good first issue`** to contribute directly
