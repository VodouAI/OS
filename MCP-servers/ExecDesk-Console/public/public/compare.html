What makes Vodou different

Intelligence before the LLM, not after.

🧠

BrainLoader Pre-routing

Before your LLM sees the query, BrainLoader matches intents, extracts parameters, and fires MCP tools in parallel. The LLM formats results — it doesn't decide what to run.

88 intent mappings, deterministic routing
💾

Persistent Memory

Hybrid search combining FTS5 keyword matching, vector embeddings, recency weighting, and category scoring. Memories persist across sessions with structured Why/How fields.

4 ranking signals fused via RRF
⚡

Parallel MCP Orchestration

13 MCP servers with 110+ tools. "cpu memory disk network" fires 4 tools simultaneously across different servers. Auto-reconnect on failure.

13 servers, auto-healing connections
🎯

Interactive Skills

45 skills with stopping points, AGENT_ACTIONS workflows, variable capture, and loop execution. The gateway drives every step — the LLM can't skip or fake output.

45 skills with deterministic execution

Start in 30 seconds

Point any OpenAI-compatible tool at your local Vodou gateway.

// .continue/config.json
{
  "models": [{
    "title": "Vodou (Vodou)",
    "provider": "openai",
    "model": "vodou-default",
    "apiKey": "local",
    "apiBase": "http://127.0.0.1:8765/v1"
  }]
}
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:8765/v1",
    api_key="local"
)

stream = client.chat.completions.create(
    model="vodou-default",
    messages=[{"role": "user", "content": "check system status"}],
    stream=True
)

for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="")
import OpenAI from 'openai';

const client = new OpenAI({
  baseURL: 'http://127.0.0.1:8765/v1',
  apiKey: 'local'
});

const stream = await client.chat.completions.create({
  model: 'vodou-default',
  messages: [{ role: 'user', content: 'what changed today?' }],
  stream: true,
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content || '');
}
# Streaming
curl -s http://127.0.0.1:8765/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "vodou-default",
    "stream": true,
    "messages": [{"role": "user", "content": "hello"}]
  }'

# Non-streaming
curl -s http://127.0.0.1:8765/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "vodou-default",
    "messages": [{"role": "user", "content": "cpu memory disk"}]
  }' | jq '.choices[0].message.content'
